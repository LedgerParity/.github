# LedgerParity organization files

![LedgerParity](assets/banner.png)

Organization-level files for the LedgerParity organization on GitHub.

- `profile/README.md` — rendered on the organization profile page.
- `assets/` — banner, lockup, and mark images referenced by the profile README.
- `CODE_OF_CONDUCT.md`, `GOVERNANCE.md`, `LICENSE` — organization-wide
  community and governance files.

Repository-specific documentation lives in each repository
(`ledger-parity-core`, `ledger-parity-connectors`, `ledger-parity-cli`),
including per-repository `CONTRIBUTING.md`, `SECURITY.md`, `DECISIONS.md`,
and `PROJECT_HANDOFF.md`.
